# Dev Tools

Install Dev Tools from the Summerfield AI Zoo marketplace to use its three skills:

- `dev-tools:code-quality-review` provides optional, read-only code review with findings tied to evidence.
- `dev-tools:coding-preferences` applies relevant coding preferences to implementation, review, explanation, and engineering prose.
- `dev-tools:superb-skills` designs, reviews, and evaluates reusable instructions, skills, plugins, and contracts; it also critiques and explains benchmark evidence and helps design studies without running them.

## Optional integrations

Dev Tools can consult `remember-me` for relevant personal context and `research-briefing` for evidence that affects instruction design. Both are optional. Dev Tools continues with the information available when either skill is missing.

## Moving from Work Smarter

Work Smarter 2.0 no longer includes Superb Skills. Install Dev Tools separately and use `dev-tools:superb-skills` for reusable instruction work. Work Smarter's research, teaching, personal-context, and backup skills remain available in that plugin.

Installing Dev Tools does not read, change, or migrate personal data. Personal-data updates happen only through an authorized request.

See the [Issue 20 acceptance report](../../benchmarks/dev-tools-acceptance.html) for the tested behavior, evidence limits, and public release gate.
