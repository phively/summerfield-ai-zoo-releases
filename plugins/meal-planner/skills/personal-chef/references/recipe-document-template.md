# Canonical recipe document template

Use this semantic template when creating or reformatting a canonical recipe. Read [native artifact storage and formatting](../../../shared/artifact-formatting.md) first. Render the structure with native Google Docs features; do not paste Markdown syntax, table pipes, or raw HTML into the Doc.

## Document structure

1. Recipe title using the native `Title` paragraph style.
2. A compact native metadata table containing Recipe ID, status, version, yield, active time, total time, and last updated. Keep the table as a table rather than aligned text.
3. A `Source` heading using `Heading 1`, with author and website when known plus a descriptive named link to the original recipe, or a clear original-recipe designation.
4. An `Ingredients` heading using `Heading 1`, followed by a native table with quantity, unit, ingredient, preparation, and constraint-sensitive notes when a table improves usability; otherwise use a native bulleted list.
5. An `Instructions` heading using `Heading 1`, followed by a native numbered list.
6. `Current adaptations`, `Prep ahead`, `Storage and leftovers`, and `Unresolved details` headings using `Heading 1` when applicable, with `Heading 2` for any meaningful subsection and concise native bulleted lists for the notes.
7. Explanatory or historical paragraphs using `Normal text`. Targeted preparation or historical context belongs only when it explains a rating, modification, or prior plan, and must remain clearly distinguishable from current instructions.

Bold, larger, or indented text does not satisfy a required paragraph style. When creating or reformatting a recipe, read back each required title, heading, paragraph, list, table, and link and repair any mismatch before reporting the recipe as published.

Preserve useful original wording without reproducing copyrighted source text beyond what is permitted. Do not fabricate missing quantities, timing, provenance, approval, or outcomes.
