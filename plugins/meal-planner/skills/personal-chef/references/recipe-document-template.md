# Canonical recipe document template

Use this semantic template when creating or reformatting a canonical recipe. Read [native artifact storage and formatting](../../../shared/artifact-formatting.md) first. Render the structure with native Google Docs features; do not paste Markdown syntax, table pipes, or raw HTML into the Doc.

## Document structure

1. Recipe title using the native title style.
2. A compact native metadata table containing Recipe ID, status, version, yield, active time, total time, and last updated.
3. A `Source` heading with author and website when known plus a descriptive named link to the original recipe, or a clear original-recipe designation.
4. An `Ingredients` heading followed by a native table with quantity, unit, ingredient, preparation, and constraint-sensitive notes when a table improves usability; otherwise use a properly formatted bulleted list.
5. An `Instructions` heading followed by a native numbered list.
6. `Current adaptations`, `Prep ahead`, `Storage and leftovers`, and `Unresolved details` headings when applicable, using concise bulleted lists.
7. Targeted preparation or historical context only when it explains a rating, modification, or prior plan. Keep current instructions clearly distinguishable from historical context.

Preserve useful original wording without reproducing copyrighted source text beyond what is permitted. Do not fabricate missing quantities, timing, provenance, approval, or outcomes.
