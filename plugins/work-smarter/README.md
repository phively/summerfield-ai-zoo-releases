# Work Smarter

Install Work Smarter from the Summerfield AI Zoo marketplace to use its research, teaching, personal-context, and backup skills.

## Workflows

- `work-smarter:research-briefing` investigates substantive questions with current evidence and explicit uncertainty.
- `work-smarter:teach-me` supports adaptive teaching, practice, learning plans, and advice within supported domain modules.
- `work-smarter:remember-me` maintains a personal-context index and routes topics to their owners.
- `work-smarter:record-backup` backs up authorized durable records to GitHub.

Work Smarter 2.0 removed the bundled Superb Skills entry point. Install Dev Tools separately and use `dev-tools:superb-skills` for reusable instruction work. Work Smarter does not depend on Dev Tools.

Remember Me can route coding-convention requests to `dev-tools:coding-preferences` when Dev Tools is available. That integration is optional; Work Smarter continues with the context available if it is not installed.

## Existing records

Installing or updating Work Smarter does not move, copy, or delete user records. Existing records remain at their current destinations unless the user authorizes a transfer.

Report a personal-data update only after its outcome has been verified.
