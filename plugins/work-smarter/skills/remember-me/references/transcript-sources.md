# Requested transcript sources

Read this reference only for a specific transcript-save request or a targeted
request to cite/read an existing source. Ordinary wrap-up offers concern topic
updates only. A transcript request alone grants no unrelated topic update.

## Confirm the actual source

1. Identify exactly which available turns are requested, who said them, and the
   source conversation/date when known. Disclose missing earlier turns,
   attachments, tool outputs or other unavailable portions. Never reconstruct
   unavailable text or imply a complete export from partial context.
2. Propose **verbatim Markdown** and show the actual available scope,
   representation, format and exact canonical library/destination. If rendering
   or omissions mean a literal source cannot be preserved, describe that limit
   before approval; do not silently substitute a summary for verbatim content.
3. Confirm before writing. Include the specific minimized sensitive retained
   content and destination when relevant; one sufficient confirmation covers both
   gates. Secrets, credentials, unsupported inferences and unnecessary sensitive
   details remain excluded under the entrypoint's protections. If exclusion
   changes the requested representation, disclose it and confirm that scope.
   Rejection or silence produces no source. A materially changed destination or
   scope needs the missing confirmation. Pending proposals stay in conversation.

## Create and verify a separate evidence source

Default new sources to `remember-me/sources/<stable-source-id>.md` in the
confirmed library. Resolve user overrides and canonical authority before writing.
Allocate a stable source ID, not a title-only identity; create no empty source
folders or placeholder sources. Preserve a clearly equivalent existing source
location. Do not put a transcript in a current topic or `history.md`.

Keep source metadata separate from the verbatim turn bodies. Include:

- stable source ID, owner, provider and library/container, immutable resource ID
  and permalink when supplied (resolved durable path otherwise);
- representation (`verbatim Markdown`), source attribution, actual available
  scope, recorded date when known, omissions and handling restrictions;
- stable turn/section anchors, such as `turn-1`, with speaker attribution; and
- verified creation/update status grounded in fresh canonical readback.

Preserve the confirmed available turns faithfully, in order, without inventing
speakers, wording or unavailable context. Resolve any uncertain creation by
stable source identity before retrying so an acknowledgement loss does not cause
an unnecessary duplicate. Use [ordinary-save verification](record-management.md#ordinary-save-verification)
for consent, canonical readback, failure reporting and bounded recovery. Inspect
actual stored text, scope metadata and identity before describing it as verified.
A source saved but not verified is unverified even if the create call succeeded.

## Cite without changing current authority

Only an authorized bounded topic update may add a concise citation. Identify the
source's provider/container, resource ID and canonical permalink when available,
or resolved durable path otherwise, plus stable source ID and a turn/section
anchor when needed. For example: `Source: <canonical permalink>#turn-1
(source RM-SRC-2026-10-17-01, provider/container/resource identity)`; for local
Markdown use a resolved durable source path plus `#turn-1`. Read back the cited
source and resolve the anchor and source identity, then verify the changed topic
and any affected index pointers. A filename, line number or title alone is
insufficient. Do not create a competing topic schema or expand the index into a
transcript catalog.

Sources are historical evidence. The identified current topic or specialist
record remains authoritative for current state. An old preference in a source
must not replace a current preference without a separately authorized correction
and any applicable conflict confirmation. Retrieve only relevant source sections.
Preserve household attribution, specialist ownership and forgetting boundaries:
a source is not an exception that permits retaining information the user asked
to forget. Report inaccessible or externally owned copies outside this workflow's
control rather than implying they were deleted.
