# Professional Development

Turn strategic career priorities into practical development work and keep its current state coherent.

## Boundaries

- `career-direction` owns reusable career goals, constraints, positioning, target roles, hypotheses, and high-level development priorities: what matters and why.
- This skill owns the execution layer: capability gaps, development goals, credentials, courses and other resources, prioritization, sequencing, progress, completed evidence, dependencies, review dates, and next actions: what the user is doing about it.
- Do not own general career discovery, specific-opportunity fit, ordinary interview preparation, or resume/profile production.
- Do not duplicate `teach-me` pedagogy. Career Coach selects and tracks the development objective; an optional teaching or practice capability may design or run learning when the user has a genuine learning goal.

## Workflow

1. Read the canonical [shared records and handoff contracts](../../shared/handoff-contracts.md). Retrieve the relevant current Career Direction context first, including the priority's source, evidence class, target roles, constraints, and unresolved uncertainty. Locate and read the relevant current professional-development record before proposing changes.
2. Translate confirmed strategic priorities into actionable development goals. Give each goal a stable `PD-...` identifier and distinguish capability acquisition from credential acquisition.
3. Compare capability gaps and candidate investments by career relevance, urgency, expected evidence, effort, cost, prerequisites, portability, and fit with the user's constraints. Preserve unknowns rather than inventing outcomes.
4. Choose a proportionate development approach and sequence. Keep courses, practice, projects, mentoring, credentials, and other resources as options rather than assuming a course or credential is required.
5. Record or update current progress, completed evidence, dependencies, target or review dates, provenance, and the smallest useful next action in the canonical professional-development record. This skill is the sole writer; do not create skill-local copies. Require explicit user confirmation before persisting an inferred goal or committing consequential cost, time, or credential activity.
6. Reassess priorities when new evidence, changed direction, completed work, or a blocked dependency changes the plan. Route durable changes to reusable strategic priorities back to `career-direction`; keep detailed execution here.

## Supporting capabilities

- When available, use `research-briefing` only when current external facts materially affect a credential, course, labor-market, employer, industry, or geographic decision. If it is unavailable, label affected claims unverified or unknown. Keep sourced facts separate from Career Coach judgments and user preferences.
- When available, use `teach-me` only when the user has a genuine learning or practice objective. Do not invoke it merely to make a roadmap, choose a resource, or record progress; if it is unavailable, continue locally and do not imply a handoff occurred.
- When available, use `remember-me` only for narrow stable personal context that is not owned by Career Coach and materially affects the plan. If it is unavailable, continue with neutral defaults.
- Continue locally when an optional capability is unavailable; never imply that an unavailable handoff occurred.

## Output

Match depth to the request. Distinguish confirmed current state, user goals, supported gaps, candidate investments, unknowns, completed evidence, and proposed next actions. A plan is not proof of capability, experience, or credential completion.
