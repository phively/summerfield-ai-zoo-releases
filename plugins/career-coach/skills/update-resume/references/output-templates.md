# Output Templates

Select the smallest format that completes the user's request.

## Narrow revision

Use for one bullet, summary, skills section, or small group of edits:

1. Ready-to-use revision
2. One concise rationale when useful
3. Confirmation question or unsupported caveat only if material

Do not add a full posting analysis or gap report unless requested.

## Prioritized review

Use when the user asks what to change but not for a complete rewrite:

1. Three to seven highest-value changes
2. Sample wording for the most important changes
3. Material evidence gaps or confirmation questions

## Full role-to-resume review

Use when requested or needed for a comprehensive update:

1. Role priorities
2. Evidence map
3. Recommended positioning and section order
4. Proposed revisions grouped by resume section or position
5. Material gaps and confirmation questions
6. Claim-verification notes

## Evidence map

| Requirement | Importance | Evidence | Evidence class | Resume coverage | Recommended action |
|---|---|---|---|---|---|

Use qualitative importance and evidence labels unless the user asks for a defined scoring method.

## Wording status

Separate proposed language into:

- **Ready to use:** Explicitly supported and verified.
- **Confirm first:** Potentially useful but dependent on a supported inference, unresolved scope, estimate, or source conflict.
- **Not recommended:** Unsupported or materially overstated.

## Confirmation queue

Ask only questions that could unlock an important claim or correct a material ambiguity. Include the claim the answer would support so the user can judge whether answering is worthwhile.

## Complete resume

Provide a clean candidate-facing version without evidence labels, followed by a separate verification note. Exclude every confirmation-required claim from the clean version until confirmed.
